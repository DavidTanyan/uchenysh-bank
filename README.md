# 🪙 Ученыш Банк

Система учебных баллов для учеников **STEMLAB Tbilisi** (1–11 классы).
Учителя начисляют и списывают баллы, а все, у кого есть ссылка, видят одни и те же счета в реальном времени.

**Сайт:** https://davidtanyan.github.io/uchenysh-bank/

## Возможности

- Счета учеников по классам 1–11
- Начисление и списание баллов с комментарием
- История операций с именем учителя
- Рейтинг учеников
- Режим учителя по паролю
- Общее хранилище данных в Firebase Firestore

## Структура

```
index.html      — разметка
css/style.css   — стили
js/app.js       — логика приложения и работа с Firebase
assets/logo.png — логотип
```

## Запуск локально

Откройте `index.html` в браузере или через расширение **Live Server** в VS Code.

## Технологии

HTML, CSS, JavaScript (без фреймворков), Firebase Firestore.
